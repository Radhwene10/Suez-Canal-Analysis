# Suez-Canal-Analysis
This repository contains a data-driven analysis of the Suez Canal and its role in global maritime trade between 2014 and 2024. The project examines traffic volumes, cargo composition, vessel origins and destinations, and financial performance over a ten-year period, highlighting how geopolitical events, infrastructure developments, and global trade dynamics have influenced canal usage.

The goal of this repository is to provide a clear, research-oriented overview of the Suez Canal as a critical global chokepoint, supported by aggregated statistics and historical trends that can be reused for academic, economic, or policy-focused work.
